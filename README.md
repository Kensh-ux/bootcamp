# 代码练习记录

> 本仓库用于记录个人编程学习与算法练习。
> 原 `c-project` 仓库改为综合代码仓库，将会包含 C、C++、Python 等多种语言。关于终端操作、杂项练习等被移动到仓库外。
> 由于纯粹为了比赛而写的算法代码与巩固知识点的练习代码不同，故单独分出 `ALGO` 目录。

## 📁 目录结构说明
- **`ALGO`**：算法竞赛相关（衍生练习）
- **`c-projects`**：包含C语言、C++练习项目
  - `C/`：初试基础篇、初试进阶篇
  - `C++/`：竞赛篇、练习篇
- **`python-projects`**：Python练习项目
